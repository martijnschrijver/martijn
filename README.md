# Martijn Schrijver

Digital artist and visual designer based in the Netherlands.

I run two practices. At martijnschrijver.com I make surreal digital artworks based on nature, combining animals with landscapes, textures and natural forms. With Tref I run a design studio for branding, visual identity and digital design.
